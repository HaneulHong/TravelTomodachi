### 가계부 · 오늘 카드 · 동선 최적화 · 예약 번호 — 2026-09-24 (PR #10, main에 머지됨)
벤치마크(트리플·Wanderlog·TripIt 등)에서 고른 것. 전부 무료 서비스만 쓴다.
- **공동 가계부 + 정산** (일정 메뉴 → 가계부): 누가 냈고 누구끼리 나누는지만 적으면
  "누가 누구에게 얼마"를 송금 횟수 최소로 계산. 통화 섞여도 됨 — 환율이 있으면 한 통화로,
  없으면(오프라인) 통화별로. 정산 통화는 사람마다. 환율은 ExchangeRate-API 공개판(무료,
  출처 표시), 12시간 기기 저장. DB: `supabase/expenses.sql`
- **오늘 카드** (홈 맨 위, 여행 기간에만): N일차·도시·현지 시각, 다음 일정까지 남은 시간,
  날씨(Open-Meteo 무료), 환율. 여행을 열면 여행 중엔 오늘 날짜로
- **동선 최적화** (일정 메뉴): 직선거리로 가장 짧은 순서를 제안 → 사람이 적용.
  첫 일정·구간 일정·좌표 없는 일정은 고정. 시각과 어긋나게 되면 미리 경고
- **예약 번호** 칸(눌러서 복사) + **캘린더로 내보내기**(.ics, 각 도시 현지 시각 → UTC).
  캘린더 내보내기는 웹 전용 — 앱은 파일 저장 플러그인이 없어 메뉴를 숨김

## 작업 방식

1. Claude가 main에서 새 브랜치를 따서 작업 → 커밋 → 푸시
2. Claude가 PR을 만들고 주소를 준다 (`gh`)
3. 사용자가 GitHub에서 확인하고 머지 → Cloudflare가 자동 배포
4. DB 변경이 있으면 `supabase/*.sql`을 **머지 전에** SQL Editor에서 실행
