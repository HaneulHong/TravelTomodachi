### 이동 시간 계산 고침 — 2026-09-25 (이 브랜치, 머지 전)
- **수단을 누르면 시간이 박제되던 것**: 수단 카드를 누르기만 해도 "직접 입력"이 되어, 누를 때의
  숫자(대개 처음 추천된 차량 시간)가 고정되고 다른 수단을 골라도 반영되지 않았다. 수단 비교 칸도
  '조회 중'에 멈췄다. 이제 상태가 셋이다(`src/domain/legChoice.ts`):
  1. 안 고름 → 추천 수단의 조회 시간
  2. 수단만 고름 → 그 수단의 **조회 시간을 따라감** (DB에 수단만 저장, `leg_is_manual=false`)
  3. −/+로 시간을 고침 → 그 시간 고정 (「직접 입력」)
  직접 입력한 구간도 비교용으로 조회해서 세 수단 시간이 늘 보인다. 수단만 골라도 「자동 계산으로 되돌리기」
- **추천이 거의 늘 차량이던 것**: 여행자는 대개 차가 없다 — 도보·대중교통 중에서 추천하고, 둘 다 없을
  때만 차량. (명동 → 경복궁: 도보 36 · 대중교통 25 · 차량 11 → 전에는 차량, 이제 대중교통)
- **대중교통 거리가 터무니없던 것**(2.7km 구간이 80km): 탄 구간의 선이 정류장 사이 직선의 3배+1km를
  넘으면 믿지 않고 정류장 두 점을 잇는다. 대중교통 구간 거리는 좌표로만 잰다
- 대중교통 조회 실패 시 1.5초 뒤 한 번 더 묻는다. 같은 구간을 동시에 두 번 묻지 않는다
- 장소 없이 만든 일정 앞 구간: 「이동 정보 없음 · 탭해서 입력」 대신 「장소를 넣으면 자동 계산」
- DB 변경 없음 (기존 leg_mode·leg_minutes·leg_is_manual 칸을 그대로 씀)
- ⚠️ 80km의 정확한 원인은 이 환경에서 Transitous를 부를 수 없어 확인 못 함 — 방어 코드로 막음
